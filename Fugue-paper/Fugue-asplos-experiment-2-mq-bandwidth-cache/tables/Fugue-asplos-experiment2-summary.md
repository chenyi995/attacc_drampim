# Experiment 2 — MQ Attention Sensitivity to Link Bandwidth and KV Cache

左图 13 个 B × 18 个 Q，固定 C=1024；右图 8 个 C × 18 个 Q，固定 B=300 GB/s。仅 MQ 模式。

| C（tokens） | 实验 2 粗网格中的 MQ/GPU 交叉区间 |
| --- | --- |
| 0 | 无交点；采样内 GPU 更快 |
| 128 | 64–96 |
| 256 | 128–192 |
| 512 | 256–384 |
| 1024 | 512–768 |
| 2048 | 1024–1536 |
| 4096 | 1536–2048 |
| 8192 | 无交点；采样内 MQ 更快 |

这是热图的粗网格区间；C=1024 的整数补测细节见实验 1，不能用本表覆盖它。每格记录的颜色值为 `(T_GPU−T_MQ)/max(T_GPU,T_MQ)`；蓝色为 MQ 更快，橙色为 GPU 更快，白色表示相等，绝对值是较快方案相对较慢方案的延迟降低比例。50% 表示 2×，75% 表示 4×；没有颜色截断或平滑插值。
