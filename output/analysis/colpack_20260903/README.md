## 口径

- **布局**:column-packed extent 模型。1024 B 的 DRAM row 装 256 个 token,
  一个 col(32 B)装 8 个;k=8 的修正正好一个 col。每条 channel 的真实 extent 交给
  Ramulator 跑一次仿真,由 row buffer 数 ACT。**A3b 里一个 head 自己的 repair 连成
  一条**(head 内共享行),master/diff 各档把**所有 head 的 repair 并成一条**放在 diff
  通道 —— 跨 head 那一步才是 master/diff 分离的收益。
- **`heads_per_hbm` 按 per-GPU 的 stack 数算**(`d3a3c4c`):GPT-175B 3、LLAMA-65B 2、
  LLAMA-33B 6、GPT-13B 4、LLAMA3-8B 8、LLAMA-7B 32。
- **workload**:C=16、sys=256(整块),baseline 上下文 `18 × 256 = 4608`,k=8。
  旧的 C=32 / sys=16 归档在 `workload/archived/2026-09-03_pre-C16/`。
- **档位**:baseline 没有 A3/A3a(用户裁决);其余点本应是 A3b A4 A5 A6。
- `N-hi`(wl_N64)按历次裁决放弃。
