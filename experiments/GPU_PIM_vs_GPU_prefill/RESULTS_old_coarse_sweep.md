Crossover (A6 = A4): n_q ≈ 25–30 on NVLink3, n_q ≈ 100–110 on PCIe4.
Below it the PIM's single-pass (or few-pass) scan of the 8192 reused rows
(7 ms / 32 layers at n_q <= 4) undercuts the link read-back of 16 MB/layer
(NVLink3 2 ms, PCIe4 17 ms per 32 layers) plus the GPU's skinny attention;
above it the PIM's passes (ceil(n_q/4)) grow linearly and the GPU's 128-row
Q blocks amortise.  CacheBlend's own recompute rows (r·L = 1229 at r=0.15)
put it far above the crossover regardless of n_new; only r -> 0 or EPIC with
a tiny new turn (<= 25 tokens on NVLink, <= ~100 on PCIe) reach it.

Crossover n_q (A6 = A4): NVLink3 ~25 (7B) / ~45 (65B) / ~50 (175B); PCIe4 ~100 (7B) / ~150 (65B) / ~230 (175B).
