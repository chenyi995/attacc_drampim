## 3. 受损任务：缺哪些档、为什么

**34 档全部死于节点资源耗尽（磁盘满 / OOM），没有一档是引擎缺陷。**
三个根因都已修掉（见 commit `a798e8a`），补跑不会重演：

1. **`/tmp` 太小** — node5/node6 的 `/tmp` 在 `/` 上，只有 49–62G，
   而一个 trace 重的档要 ~128G。已切到 `/localdata`（3–33T），六节点探针 6/6 通过。
2. **缓存池指数膨胀** — 每次 publish 把任务 seed 来的内容重写回去，
   1MB 两小时后变成 193GB，池子共 499GB，压在一个 98% 满的卷上。已关闭 publish。
3. **内存尖峰被 OOM killer 命中** — 放置改用投影内存而非当前内存。
