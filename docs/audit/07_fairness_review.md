# 块 07:逐实验公平性审查(准则见块 00 §1)

目标读者:要质疑"对比是否偏袒我方"的人。逐实验过 P1–P6,
结论分三档:**通过**(有证据)/**须声明**(公平但正文必须写明口径)/
**存疑**(待补证据或宸逸裁决)。审查日期 2026-08-22。

## 1. A 系列(放置消融)与拐点实验

| 检查项 | 准则 | 结论 | 证据/说明 |
|---|---|---|---|
| A1 基线是原版 AttAcc 而非削弱版 | P1 | **通过** | 测试 `test_ablation_a1_reproduces_the_original_attacc_legacy_report`:时间/能耗对 legacy 报告逐位(链路层除外且方向是给 A1 加成本前一致) |
| GPU 对手用最强模型 | P1 | **通过** | A 系列默认 `--gpu-model flash`(FlashAttention 风格显式 tile 模型,比 roofline 更接近真实 GPU 上限;对 GPU 有利=对我方结论保守) |
| flash 模型的软输入 | P6 | **须声明** | `src/gemm_table.py` 头注自认:cuBLAS GEMM 表来自外部实测 CSV(可溯源);FlashAttention 效率曲线是**从 Dao 2023 论文图上读的近似值**,"the one soft input"。影响方向:高估 GPU 注意力效率 → 对我方保守;但进正文须注明来源性质 |
| 所有 A 配置同一负载/padding/能耗表 | P2/P3 | **通过** | 同一 workload JSON、同一 `_tier_shapes` padding、同一 `ENERGY_TABLE`;A1–A6 走同一 `run_ablation_report` 代码路径(P5) |
| A4 的 KV 读回代价是否是"给对手加税" | P1 | **须声明** | `prefill_kv_readback=True`:KV 驻 PIM 时 GPU prefill 必须把复用行拉回——物理必然,非人为削弱;且有 `--no-prefill-kv-readback` 反事实开关可量化该项。正文应声明该假设与开关 |
| 拐点实验 A4 vs A6 | P4/P5 | **通过** | 同频、同链路、同 policy、同一解析路径,只变放置;p\* 对 L 的不敏感性单独验证(pgridL) |

## 2. C 系列(MQ 微架构)

| 检查项 | 准则 | 结论 | 证据/说明 |
|---|---|---|---|
| C1 基线频率 | P1 | **通过** | C1 = AttAcc 原样,0.666 GHz 是 AttAcc 论文自己的 GEMV 频率(其 §5.1,tCCDS 定) |
| **C3 头条数字(3.63×@1.3 GHz)与 C1(0.666 GHz)频率不同秤** | P4 | **须声明** | 同频行存在且已实测:C3@0.666 GHz = 2.29×/(16,2)、2.90×/(32,4)——**纯命令/微架构收益**;1.3 GHz 行的额外收益来自 PE 提频,伴随实测面积代价(+84.9%/(16,2)、+220%/(32,4),C-abl-3)。正文报头条时必须并排给同频行与面积代价,不许只报 1.3 GHz 行 |
| PE 提频只提 PE,不偷改 DRAM 时序 | P3 | **通过** | `mq_interval_cycles` 里频率只进 `pe_cycles` 项;DRAM 侧 nCCDAB 地板与 IDD7 功耗拉伸不随 PE 频率放松(块 06 §3 逐行核对) |
| C2 是解析合成而非实测 | P5 | **须声明(方向有利于被排除方)** | C2 = `ceil(N/k)×t1` 外推(json `c2_model` 字段自述),**忽略复制的写入与一致性开销 → 高估 C2**;C2 的结论是"k≥8 才追平"(排除项),给它有利的估计使排除更稳。正文引用时须写明"解析上界" |
| MQ 时序模型 vs RTL 的交叉验证 | I6 | **通过** | 模型经微基准定标(70 cycles/行平台期);RTL 三路独立复核:数值逐位等价、MVSB 串行地板 256·n_q、寄存器清单(`DATAFLOW.md` §5) |
| C-abl-2(总线转向) | P1 | **通过** | 转向惩罚是**给我方方案加的约束**(保守方向);"窄下行"被 ≤0.84% 的实测收益关闭 |
| bank-whole 的丢弃三角照样计费 | P1 | **通过** | 被因果丢弃的上三角行"照样被扫、照样计费"(块 04 §5)——不白拿丢弃的好处 |

## 3. 面积对比(C-abl-3,详见块 06)

| 检查项 | 准则 | 结论 | 证据/说明 |
|---|---|---|---|
| 倍数口径:同工艺(N28)同 corner(SS)同流程(Genus) | P3 | **通过** | 12 点同一 `run_syn.tcl` 配方 |

## 5. 汇总:进正文前必须写明的公平性声明清单

1. C3 头条须并排:同频(0.666 GHz)纯微架构收益行 + 提频行的面积代价;
2. C2 为解析上界(对 C2 有利);
3. flash GPU 模型的 FlashAttention 效率曲线为文献读图值(对 GPU 有利);
4. A4 的 KV 读回假设及其开关;
5. 面积只报倍数/占比,绝对值口径张力(块 06 §5.2)如实引用;
6. (16,2)@匹配点是否在预算内=悬置,不得提前主张。
